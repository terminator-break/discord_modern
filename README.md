# 🤖 Discord Bot — Модерация + Мини-игры

Многофункциональный Discord-бот на Python с модульной архитектурой, поддержкой слэш-команд, системой экономики и инструментами модерации.

---

## ⚙️ Установка и настройка

### Требования

- Python 3.10 или новее
- pip

### 1. Клонируйте или скачайте проект

```bash
git clone <url-репозитория>
cd discord_bot
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Создайте файл `.env`

Скопируйте пример и заполните своими данными:

```bash
cp .env.example .env
```

Откройте `.env` и укажите токен бота:

```
DISCORD_TOKEN=ваш_токен_здесь
GUILD_ID=ID_вашего_сервера   # рекомендуется при разработке
```

### 4. Получите токен бота

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
2. Создайте приложение → раздел **Bot** → скопируйте токен
3. Включите **Privileged Gateway Intents**: `Server Members Intent` и `Message Content Intent`

### 5. Пригласите бота на сервер

В разделе **OAuth2 → URL Generator** выберите:
- Scopes: `bot`, `applications.commands`
- Bot Permissions: `Administrator` (или минимально необходимые права)

### 6. Запустите бота

```bash
python main.py
```

При первом запуске автоматически создастся файл `bot.db` с нужными таблицами.

## 🛡️ Команды модерации

| Команда | Описание | Права |
|---------|----------|-------|
| `/kick @user [причина]` | Кикнуть участника | Kick Members |
| `/ban @user [причина]` | Забанить участника, отправить ЛС | Ban Members |
| `/unban user_id [причина]` | Разбанить по ID | Ban Members |
| `/mute @user длительность [причина]` | Выдать мут (30s, 10m, 2h, 1d) | Manage Roles |
| `/unmute @user` | Снять мут вручную | Manage Roles |
| `/clear [количество]` | Удалить N сообщений (1–100) | Manage Messages |
| `/warn @user причина` | Выдать предупреждение (3 → автобан) | Manage Messages |
| `/warnings [@user]` | Показать предупреждения | Manage Messages |

### Авто-функции модерации

- **Авто-роль Muted** — если роль `Muted` не существует, бот создаёт её и настраивает права на всех каналах
- **Авто-снятие мута** — через заданное время мут снимается автоматически
- **Автобан** — при достижении порога предупреждений (по умолчанию 3) участник баниться автоматически

## 🎮 Команды мини-игр и экономики

| Команда | Описание |
|---------|----------|
| `/daily` | Получить ежедневный бонус (100 монет, раз в 24ч) |
| `/balance [@user]` | Показать свой или чужой баланс |
| `/pay @user сумма` | Перевести монеты другому участнику |
| `/coinflip ставка выбор` | Монетка: орёл/решка, шанс 50/50, выигрыш ×2 |
| `/roll ставка число` | Кубик 1–6: угадай число, выигрыш ×3 |
| `/rps ставка выбор` | Камень-ножницы-бумага против бота |
| `/top` | Топ-10 богатейших игроков сервера |

### Экономика

- **Начальный баланс:** 100 монет (при первом использовании)
- **Ежедневный бонус:** 100 монет (кулдаун 24 часа)
- Все данные хранятся в SQLite (`bot.db`)

## 🔧 Конфигурация (`.env`)

| Переменная | По умолчанию | Описание |
|-----------|-------------|----------|
| `DISCORD_TOKEN` | — | **Обязательно.** Токен бота |
| `GUILD_ID` | — | ID сервера для быстрой синхронизации команд |
| `PREFIX` | `!` | Префикс для обычных команд |
| `WARN_THRESHOLD` | `3` | Количество предупреждений до автобана |
| `STARTING_BALANCE` | `100` | Начальный баланс новых игроков |
| `DAILY_REWARD` | `100` | Размер ежедневного бонуса |
| `DB_PATH` | `bot.db` | Путь к файлу базы данных |

## 🚀 Советы по деплою

- Для продакшена используйте процесс-менеджер: `pm2`, `systemd` или Docker
- **Никогда не публикуйте `.env`** — добавьте его в `.gitignore`
- Рекомендуется запускать бота под отдельным системным пользователем

```bash
# .gitignore
.env
bot.db
__pycache__/
*.pyc
```
